# YanzuSelfie - AI美颜相机

功能特点

- 看起来像正常的相机APP
- 实时摄像头预览
- 点击拍照按钮
- 不管拍什么，保存的都是吴彦祖的照片

使用方法

1. 打开APP，允许相机权限
2. 看着预览，摆个帅气的姿势
3. 点击拍照按钮
4. 显示拍照中...
5. 打开相册一看：哇，是我吗？这么帅

整蛊技巧

- 拿给朋友：试试这个AI美颜相机，拍出来超帅
- 自己测试：拍一张，打开相册，自己都被骗了
- 社交媒体：假装发自拍，其实发彦祖

技术信息

应用名称：AI美颜相机
包名：com.yanzuselfie.app
版本：1.0
最低系统：Android 8.0 (API 26)
目标系统：Android 14 (API 34)

注意事项

纯娱乐APP，不要当真
照片保存在：相册/Pictures文件夹
文件名格式：YanzuSelfie_年月日_时分秒.jpg

更换照片

如果想换照片：
1. 找到 YanzuSelfie/app/src/main/res/drawable/yanzu.jpg
2. 替换你自己的照片（保持文件名不变）
3. 重新构建APK
